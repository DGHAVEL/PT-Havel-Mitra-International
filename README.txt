PT HAVEL MITRA INTERNATIONAL - MODERN WEBSITE

Versi ini adalah redesign website modern berdasarkan isi dan identitas visual company profile PPT.

FITUR:
- Responsive desktop / tablet / mobile
- Sticky transparent navigation
- Navigation berubah saat scroll
- Scroll progress bar
- Scroll reveal animation
- Hover animation pada card
- Product gallery dengan lightbox
- WhatsApp CTA
- Phone / email / Google Maps clickable
- Tidak menggunakan framework atau CDN eksternal

STRUKTUR:
index.html
assets/logo.jpg
assets/slides/slide-01.jpg s/d slide-15.jpg

HOSTINGER:
Upload isi folder ini ke public_html.
Pastikan index.html berada langsung di public_html dan folder assets berada di public_html/assets.
